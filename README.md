# nlsm-lax-agent

2次元非線形シグマ模型のLax接続の候補を探索し、検証するための研究用ソフトウェアです。現在は要件定義に基づいて外部設計を整理する段階で、計算ライブラリとエージェントは未実装です。

まず読む文書は、[要件定義](docs/requirements.ja.md)です。

現在の確認対象は、[外部設計：利用方法と操作](docs/external-design.ja.md)です。

## 文書の順序

| 段階 | 決めること | 現在の状態 |
| --- | --- | --- |
| 1. 要件定義 | 誰が何に使い、どの機能と結果を必要とするか | [要件定義書](docs/requirements.ja.md)を後続設計の基準とする |
| 2. 基本設計 | 利用者から見た操作と入出力、それを支える構成と役割 | [外部設計の全体像](docs/external-design.ja.md)を確認する段階 |
| 3. 詳細設計 | 数式の規約、入力・出力の形式、処理と判定の手順 | 基本設計の確認後に整理する |
| 4. 実装・試験計画 | 作る順序と、各要件を満たしたことの確認方法 | 詳細設計に対応させて整理する |

一度に確認する文書は一つとし、上位の内容を確認してから次へ進みます。下位の文書には、対応する上位文書の見出しを示します。内部の変数名や関数名は詳細設計で定義し、要件の説明には持ち込みません。
