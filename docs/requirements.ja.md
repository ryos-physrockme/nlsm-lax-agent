# 要件定義

対象：2次元非線形シグマ模型のLax接続の探索・検証ソフトウェア。状態：確認用の草案。

## 1. 利用目的

研究者が指定した模型について、Lax接続の候補を探し、その候補が模型の運動方程式を表すかを検査する。候補の数式、成立条件、検査結果を、研究者が再検算できる形で残す。

## 2. 利用方法

| 利用方法 | 誰が計算の順序を決めるか |
| --- | --- |
| 研究者がPythonから使う | 研究者が必要な計算を選ぶ |
| CodexやClaude Codeなどから使う | 利用者の手元のエージェントが、提供された計算機能を呼ぶ |
| 付属のエージェントから使う | 付属のエージェントが、利用者の指定した範囲で探索を進める |

どの利用方法でも、同じ物理計算と検証基準を使う。外部のエージェントは、付属のエージェントを起動せずに検証と探索を利用できる。

## 3. 必要な機能

1. **模型と候補の入力。** 作用、場、結合定数、適用する領域を指定できる。利用者が用意したLax接続の候補も検査できる。
2. **候補の検証。** 運動方程式を満たすと曲率が消えるかと、零曲率条件から運動方程式全体が得られるかを分けて検査する。結果には対象の模型・候補と成立条件を明記する。
3. **候補の探索。** 記号計算と機械学習による探索を同じ検証へ接続できる。機械学習機能は追加で導入できるものとする。検査結果を使って候補を修正し、再探索できる。
4. **結果の保存と再検算。** 入力、候補、計算手順、結果、未解決の事項を保存する。保存した候補は、言語モデルを呼ばずに再検算できる。

探索で候補が見つからないことだけを根拠に、模型が非可積分だとは判定しない。確認した性質と未確認の性質を区別する。

## 4. 利用上の条件

- 付属エージェントの開発・動作確認には、Gemini APIの無料枠とローカルで動かす言語モデルを使う。接続先を変更しても物理計算を変更する必要がない構成とする。
- 利用者が指定した計算時間とメモリの上限を守る。条件を分岐して探索する場合も、探索全体の上限を守る。中断時は進捗を保存し、再開できる。
- 検証と記号計算による探索は、機械学習機能を導入せずに利用できる。

## 5. 最初に確認する到達点

主カイラル模型について、既知のLax接続を検証し、運動方程式を含まない候補と区別できること、保存した入力と候補から再検算できることを最初の到達点とする。対応する模型や探索方法は、この確認を経て段階的に増やす。
